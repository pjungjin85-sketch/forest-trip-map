# 전국 자연휴양림 한눈에

전국 자연휴양림 172곳을 지도와 목록으로 한 번에 펼쳐 놓고,
**언제 어떻게 예약하는지**와 **얼마나 경쟁이 센지**를 함께 보여 주는 정적 웹앱입니다.

숲나들e는 예약은 한 곳으로 모아 놨지만 "어디를 고를지"는 판단하기 어렵습니다.
휴양림이 지역 드롭다운 뒤에 숨어 있고, 지도는 개별 휴양림 페이지에 하나씩 박혀 있고,
선착순인지 추첨인지는 안내 페이지 텍스트로만 있고, 어디가 인기 있는지는 알 길이 없습니다.

## 두 개의 축 — 경쟁률과 인기도

이 사이트의 핵심은 **서로 다른 두 지표를 섞지 않고 나란히 놓는 것**입니다.
식당으로 치면 하나는 미슐랭 스타, 하나는 지도 별점입니다.

| | 공식 경쟁률 🏅 | 인기도 ★ |
| --- | --- | --- |
| 누가 매기나 | 산림청 국립자연휴양림관리소 | 블로그·카페에 글 쓰는 사람들 |
| 무엇을 재나 | 실제 추첨 신청 경쟁률 | 얼마나 회자되는가 |
| 언제 나오나 | 여름 성수기 추첨 후 **연 1회** | 매주 갱신 |
| 얼마나 붙나 | **상위 몇 곳만** (2026년엔 5곳) | 전체 |

경쟁률 칸이 비어 있는 것은 **인기가 없다는 뜻이 아니라 공식 수치가 없다는 뜻**입니다.
두 값을 함께 보면 교차 해석이 됩니다 — 경쟁률이 높은데 인기도가 낮으면 객실이 적어
뚫기 어려운 곳, 인기도가 높은데 경쟁률이 비어 있으면 공립이라 추첨 통계가 안 나오는 곳.

## 쓰는 법

- **예약 일정 패널**이 오늘 날짜로 다음 할 일을 계산해 D-day로 보여 줍니다.
  선착순 오픈(매주 수요일 9시), 주말추첨 접수·발표·잔여분, 여름 성수기 추첨.
- 이름·지역으로 검색합니다. **초성 검색**도 됩니다.
- 권역 9개 / 국립·공립·사립 / 예약 방식 / 특징(계곡·바다·편백…)으로 좁힙니다.
- 정렬은 **인기순 · 공식 경쟁률순 · 이름순**.
- 목록이나 지도 마커를 누르면 상세가 열립니다. 경쟁률·인기도·예약 규칙·연락처·길찾기.

기본 화면은 **자연휴양림 172곳**입니다. 숲나들e 목록에는 자연휴양림이 아닌
산림휴양시설 27곳(국립등산학교·산악박물관·동서트레일·산림레포츠파크·숲체험장 등)이
함께 들어 있는데, 버리지 않고 `그 외 산림휴양시설` 칩으로 따로 담아 뒀습니다.

## 예약 방식

숲나들e [추첨 이용안내](https://www.foresttrip.go.kr/rep/drlts/drltsUseGdnc.do?hmpgId=FRIP&menuId=001003004)에
적힌 규칙을 그대로 옮겼습니다.

| 유형 | 방식 | 곳 |
| --- | --- | --- |
| 국립 자연휴양림 | 선착순 + 추첨 | 45 |
| 국립 (아세안휴양림·그 외 시설) | 선착순 | 13 |
| 공립 | 휴양림별 상이 (월추첨·지역주민추첨 일부) | 130 |
| 사립 | 개별 예약 | 11 |

- **선착순** — 이용일 6주 전 **수요일 오전 9시**
- **주말추첨** — 매월 **4일 9시 ~ 9일 18시** 신청, **10일 16시** 발표,
  미당첨·미결제분은 **15일 9시**에 선착순으로 재오픈
- **성수기추첨** — 7/15~8/24 이용분, 접수는 5월 말~6월 중 별도 공지

> 아세안휴양림은 아세안 10개국 출신 외국인 우선예약 정책에 따라 추첨 대상에서 빠집니다.
> 추첨 대상 휴양림은 매번 숲나들e 공지로 확정되니 신청 전 확인하세요.

## 데이터

```
crawl_forest.py      숲나들e         -> data/raw_forests.json   (약 3분)
crawl_popularity.py  네이버 검색 API -> data/popularity.json     (약 3분)
data/competition.json  산림청 발표 경쟁률 (수기 관리)
        ↓
build_dataset.py     대조·가공       -> forests.json
```

의존성이 없습니다. 파이썬 표준 라이브러리만 씁니다.

```bash
python3 crawl_forest.py
NAVER_CLIENT_ID=... NAVER_CLIENT_SECRET=... python3 crawl_popularity.py
python3 build_dataset.py
```

### 숲나들e (`crawl_forest.py`)

| 쓰는 곳 | 얻는 것 |
| --- | --- |
| `GET /rep/cm/remmnAreaOrRcfclList.do` | 전체 목록 199곳 — 시도·시군구·국공사립 |
| `POST /com/sub/selectMapInfo.do` | 위경도·주소·전화·입퇴실시각·수용인원·개장년도·소개글 |
| `POST /com/selectInsttInfoList.do` | 태그·관심수·대표이미지 |

robots.txt 에서 전부 허용된 경로이고, 요청 간격을 0.4초 둡니다.
좌표·주소·전화는 199곳 모두 채워집니다.

태그 검색은 자유 입력이라 전체 태그 목록을 주는 API가 없습니다. 씨앗 태그로 시작해
응답에 실려 오는 태그를 주워 다시 검색하는 식으로 넓혀 가는데, 그래도 67곳에만
붙습니다. 그래서 **소개글에서 키워드를 뽑아 특징 태그를 따로 만들고**(계곡·바다·편백…)
필터 칩에는 그쪽만 씁니다. 숲나들e 원본 태그는 상세 화면 배지로만 남습니다.

월별 예약현황(`monthRsrvtStatus.do`)은 **로그인을 요구해서(HTTP 401)** 쓰지 않습니다.
실시간 잔여 객실은 이 사이트에 없습니다.

### 경쟁률 (`data/competition.json`)

자동 수집이 아니라 **수기 파일**입니다. 산림청이 여름 성수기 추첨 후 발표하는
보도자료 수치를 옮겨 적고 출처를 함께 박아 둡니다.

2026년 발표분(2026-06-18): 전체 평균 5.91:1 (객실 6.88 · 야영 2.22),
접수 137,691건 중 23,289건 당첨. 휴양림별 상위 5곳 —
진부령 24.81 · 무의도 13.57 · 대야산 12.79 · 신시도 12.18 · 용지봉 11.15.
최고 객실은 대야산 숲속의 집 601호 92.96:1.

**발표가 상위 몇 곳뿐이라 나머지는 `null` 로 둡니다.** 추정값을 만들지 않습니다.
새 발표가 나오면 이 파일만 고치면 됩니다.

### 인기도 (`crawl_popularity.py`)

네이버 검색 API로 휴양림 이름을 검색해 **블로그 + 카페 게시물 수**를 받습니다.
검색어는 지자체명을 뗀 정식명칭(`대관령자연휴양림`)입니다. 괄호가 붙으면 결과가
거의 안 잡히고, `대관령`처럼 짧게 자르면 무관한 글이 섞입니다.

건수는 자릿수 차이가 커서 `log10(블로그 + 카페 + 1)`을 전체 범위로 정규화해
**0~5 별점**으로 환산합니다. 목록에는 별점을, 상세에는 **원시 건수를 그대로** 적습니다 —
별점만 남기면 근거가 사라집니다.

[네이버 개발자센터](https://developers.naver.com/apps/#/register)에서 `검색` API로
애플리케이션을 등록해 Client ID/Secret 을 받습니다. 무료이고 일 25,000건입니다.
이 스크립트는 199곳 × 2회 = 398건만 씁니다.

**키가 없으면 오류 없이 건너뜁니다.** 인기도 칸이 비고 기본 정렬이 경쟁률순으로
바뀔 뿐, 나머지는 그대로 동작합니다.

## 지도 (카카오맵)

앱키가 `app.js` 의 `KAKAO_KEY` 에 들어 있습니다.
카카오 JavaScript 키는 브라우저 소스에 노출될 수밖에 없는 값이고, 등록된 도메인에서만
동작하므로 다른 사이트로 옮겨 써도 소용이 없습니다.

키를 새로 발급하거나 다른 도메인에 올릴 때는
[카카오 개발자센터](https://developers.kakao.com/console/app)에서:

1. **앱 → 플랫폼 키 → JavaScript SDK 도메인**에 주소를 등록합니다.
   경로 없이 도메인까지만 넣습니다 (`https://pjungjin85-sketch.github.io`).
2. **제품 설정 → 카카오맵 → 활성화 설정**을 **ON** 으로 바꿉니다.
3. 같은 화면의 JavaScript 키를 `app.js` 의 `KAKAO_KEY` 에 넣습니다.

지도 탭에서 키를 직접 넣으면 `localStorage` 에 저장되어 기본 키를 덮습니다.
`?key=발급받은키` 로 주소에 붙여 열어도 됩니다.

**목록·검색·상세는 지도와 무관하게 동작합니다.**
등록되지 않은 도메인(로컬 등)에서는 SDK가 401을 반환하고 키 입력 안내가 뜹니다.

## 갱신

`.github/workflows/refresh.yml` 이 매주 월요일 06:00 KST 에 돕니다.
네이버 자격증명은 저장소 Secrets 의 `NAVER_CLIENT_ID` / `NAVER_CLIENT_SECRET` 에 둡니다.

`diff_report.py` 가 이전 자료와 대조해 종료 코드로 판정합니다.

| 코드 | 뜻 | 동작 |
| --- | --- | --- |
| 0 | 바뀐 게 있음 | 커밋 & 푸시 |
| 10 | 바뀐 게 없음 | 커밋하지 않음 |
| 20 | 자료 급감 (이전의 90% 미만) | 워크플로 실패 |

휴양림 수는 거의 변하지 않습니다. 갑자기 줄었다면 수집이 덜 된 것이지 휴양림이
사라진 게 아니므로, 그 상태로 배포해 휴양림이 조용히 사라지는 일을 막습니다.

보고서는 커밋 메시지에 인라인으로 끼우지 않고 파일로만 주고받습니다.
휴양림 이름이 외부 사이트에서 오는 값이라 셸 명령에 직접 넣으면 주입에 취약합니다.
